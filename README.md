# bTunes

A desktop music studio for making tracks with an agent beside you. Each song is one file; the app plays every edit at once, and an agent can work in the open window with you, writing parts as takes beside yours for you to pick.

**Status: early access (alpha).** Things change quickly and songs from one build may not open in the next. Keep backups.

## Download

Get the latest installer from [Releases](https://github.com/benyslabs/btunes/releases/latest), Windows 10 or 11, 64-bit.

The installer is not code-signed yet, so Windows SmartScreen may say "Windows protected your PC". Choose **More info**, then **Run anyway**. Each release lists the installer's SHA-256 so you can check the download.

bTunes plays Surge XT and Vital when you have installed them yourself (both free); it does not include either. The setup guide is in each release's notes.

## What's in it

- Arrangement, piano roll, pads and step grid, mixer, versions, and in-house synths that play live
- Your own Surge XT and Vital patches, played in the song
- Renders with loudness, peak, sub, sidechain and drop checks, and export to WAV, FLAC, MP3 and more
- Agents in the open window: notes on bars and tracks, parts written as takes, review requests you answer on the Review tab
- A `btunes` command line and an MCP server for agents
